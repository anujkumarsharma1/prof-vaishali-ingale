# world/ — 3D redesign (M1, branch `redesign-3d`)
Preview at `/world/` once deployed. Not wired to the site root yet; the live front door is still `room/`.
- No build step: ES modules + importmap → vendored three.js r170 in `../room/vendor/`.
- Content comes from `../room/js/content.js` (generated by `build_content.py`; same do-not-publish rules).
- All models are procedural (no third-party assets). Sound is generated with WebAudio.
- `?static` forces the no-WebGL fallback, `?low` forces the lite tier.
- Test: serve the repo root on :8765, run `python3 room/tools/test_world.py`.
See `/workspace/site_build/REDESIGN_PLAN.md` for the full plan.

## Character (GLB)
- `world/assets/ingale.glb` (~400 KB, Draco, one baked 1024 JPEG atlas, ~22.5k tris) is generated by
  `room/tools/blender/ingale_rig.py` (model from `ingale_char.py`; Blender 4.2 LTS, headless). Clips: Idle, Walk,
  Sit, StandToSit, SitToStand; hair and pallu sway bones. Draco decoder vendored in `room/vendor/draco/`.
- Falls back to the procedural figure on load errors, without WebAssembly, or with `?proc`.
## Mobile
- Touch devices get a vertical joystick (drag up = forward). Portrait phones frame the scene higher so she stays above the card.
